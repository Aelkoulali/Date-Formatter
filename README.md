# 🗂️ Date Formatter 📅

A simple Date Formatter built with HTML, CSS, and JavaScript. It reads a date and displays formatted day, month, and year.

## ✅ Key Features
- Uses JavaScript date methods to extract:
  - `getDate()`
  - `getMonth()`
  - `getFullYear()`
- Displays the formatted result on the page

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run
Open `index.html` in your browser.
